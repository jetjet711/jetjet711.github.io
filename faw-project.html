FAW Detection Project

An AI-powered drone surveillance system developed for detecting Fall Armyworm (FAW) infestations in corn fields using aerial imagery, computer vision, and real-time object detection technologies.

Project Overview

This project focuses on early detection of Fall Armyworm infestations in agricultural corn fields through drone-based imaging and artificial intelligence.


The system captures aerial footage using a DJI drone, streams the live feed into a web application, and performs AI-based analysis to identify infected corn plants.


The platform calculates infestation percentage, highlights affected areas, and assists farmers in monitoring crop health efficiently.

Key Features

  • ✔ Real-time drone video streaming
  • ✔ AI-powered corn detection
  • ✔ Fall Armyworm infestation analysis
  • ✔ Bounding box visualization
  • ✔ Infestation percentage calculation
  • ✔ WebRTC low-latency streaming
  • ✔ Web dashboard visualization

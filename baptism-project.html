Baptism Scheduling System

A web-based parish management system designed to streamline baptism scheduling, certificate requests, and digital record management for church offices and parish administrators.

Project Overview

The Baptism Scheduling System was developed to simplify the management of baptism appointments and records for parish offices.


The system allows users to submit baptism applications online, upload required documents, and request baptism certificates digitally.


Administrators can manage schedules, verify applicant information, generate reports, and organize church records efficiently through a centralized dashboard.

System Features

📅 Online Scheduling

Users can schedule baptism appointments through an online form.

📄 Certificate Requests

Digital certificate request and processing system.

🗂 Record Management

Centralized database for storing baptism records securely.

📤 File Upload System

Applicants can upload required church documents online.

👨‍💼 Admin Dashboard

Manage requests, schedules, and records efficiently.

🔒 Secure Database

Data storage using MySQL database integration.
